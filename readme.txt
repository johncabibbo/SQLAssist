   Setup:
   SQL Assist requires Apache 2.0 or newer, PHP 7.0 or newer and MySQL 5.6 or newer.

   Place the SQLAssist directory within any web-accessible directory, then
   configure your connections in db.php. The MySQL user does not need to be
   root but does require read access to the information_schema database.
